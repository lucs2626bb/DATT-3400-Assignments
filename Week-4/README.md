
# Mood board week 4: Tilemaps and instancing
One side project for another course that I have been working on was instancing textures. In DATT 3701, Collabroative Development Project, we are assigned in a group project to develop a finsihed video game by the end of the course. One of the features my group planned to implement was an isometric map within the game engine Godot. This is a perspective where the FOV is equal and tilleable. Within the project, we tested the implementation with a sample tilesheet. This is a built in feature where you can select certian "tiles" and paint them in the TileMapLayer object where each tile is an isntance on the map of the world.
